# LSPD — учебный тир

Бесплатный любительский браузерный прототип для тренировки управления в тактических играх. Не является официальным продуктом Ready or Not или учебным пособием по обращению с настоящим оружием.

## Как начать — без установки

Откройте ссылку на игру в разделе **About → Website** справа на странице репозитория (после включения GitHub Pages).

1. Используйте компьютер с мышью и клавиатурой. Рекомендуется Chrome или Edge.
2. Нажмите **Создать профиль**, придумайте имя и пароль. Не используйте пароль от почты или других сайтов.
3. Создайте персонажа.
4. Сначала откройте **Обучение**. Оно необязательное и не портит карьеру.
5. Для зачёта нажмите **Продолжить карьеру**, выберите смену и **Войти в тир**.
6. Нажмите кнопку входа на площадке: игра захватит мышь. Чтобы освободить её, нажмите **Esc**.

Ничего скачивать, покупать и устанавливать не требуется. Для быстрого доступа сохраните страницу в закладки (Ctrl+D). На телефоне управление не рассчитано.

## Управление

- W, A, S, D — движение (работает и при русской раскладке).
- Мышь — поворот взгляда.
- ЛКМ — один выстрел со звуком (звук синтезируется в браузере). Без ПКМ ориентируйтесь на конец ствола: это стрельба от бедра.
- Удерживать ПКМ — прицеливание по крестику.
- Пробел — поднять оружие / вернуть к стрельбе.
- R — перезарядить; дождитесь полосы завершения.
- Enter — следующий выполненный шаг обучения или повтор после ошибки.
- Esc — освободить мышь, затем можно выйти в меню.
- «Речь: вкл / выкл» — реплики. Доступность русского голоса зависит от браузера и системы. Всегда есть текстовые сообщения.

## Смены

**Первая смена:** две мишени появляются вокруг игрока. Порядок свободный. Сотрудник бывает между целями, сбоку или отсутствует.

**Вторая смена:** пара в переднем секторе площадки. Сначала три попадания в левую, затем три в правую. Каждая новая пара снова начинается слева. Выстрел не в очередь расходует патрон, но не засчитывается.

**Третья смена:** за спиной напарника. Перед входом выберите третью смену и нажмите кнопку «Фонарик: F · изменить». После этого нажмите желаемую клавишу или кнопку мыши — назначение сохранится в этом браузере и появится в строке состояния на площадке. Q — выглянуть влево, прицелиться ПКМ, включить фонарик выбранной клавишей, три попадания в левую; выключить свет, Q — выпрямиться. Поднять оружие пробелом и перевести мимо своего вправо; E — выглянуть справа, вернуть оружие пробелом, прицелиться, включить свет, три попадания в правую. Выключить свет, E — выпрямиться, пробел — поднять ствол. Повторять до истечения 90 секунд. Клавишу фонарика можно выбрать перед входом (поддерживаются и кнопки мыши; если она занята стрельбой/прицелом, игра подскажет запасную кнопку). Здесь простое наведение на напарника не увольняет; перенос неподнятого оружия мимо него увольняет, выстрел убивает. Ошибка сбрасывает текущую серию, но набранные очки и полные серии сохраняются. Три точных попадания дают бонус за кучность.

Зачёт длится до 90 секунд активной игры. Заканчивается раньше при исчерпании боезапаса или сотрудников. Для первой и второй смен готовое оружие нельзя наводить на своих даже без выстрела. В третьей действуют описанные выше более мягкие правила. Обучение показывает ошибки, но не списывает сотрудников из карьеры.

## Сохранения и обмен

Прогресс хранится **в этом браузере на этом устройстве**, а не в GitHub и не на общем сервере. Не используйте режим инкогнито. Очистка данных сайта удаляет сохранения.

- В меню нажмите **Экспорт профиля** и сохраните резервную копию. Запомните пароль шифрования: восстановить его нельзя.
- Для переноса на другое устройство создайте там профиль, откройте **Импорт профиля** и выберите свою копию.
- Чтобы поделиться результатом, на экране итогов нажмите **Сохранить результат** и отправьте полученный JSON другу. Друг нажимает **Импорт результата**.
- Не публикуйте резервную копию профиля: она содержит личные данные и ключ подписи.
- Общий зал славы локальный, не синхронизируется автоматически. Текущая версия импорта добавляет результат в локальный список результатов.
- Подпись обнаруживает изменение файла, но не доказывает отсутствие читерства.

**Важно:** локальное хранилище профиля не зашифровано. Пароль защищает вход через интерфейс, а не от владельца компьютера. Шифруется экспортированная резервная копия. Это прототип, не система защиты конфиденциальных данных.

## Если что-то не работает

- После обновления нажмите Ctrl+F5.
- Не двигается мышь: нажмите кнопку входа на площадке.
- Не стреляет: проверьте, не поднято ли оружие, не идёт ли перезарядка и есть ли патроны.
- Нет речи: проверьте звук вкладки и кнопку речи; голос может отсутствовать в системе.
- Прогресс исчез: проверьте адрес сайта, браузер и режим инкогнито. Адрес localhost и GitHub Pages имеют разные сохранения. Переносите их через резервную копию.
- Не открывайте скачанный index.html двойным кликом: для модулей и криптографии нужен HTTP/HTTPS. Пользуйтесь опубликованной ссылкой.

## Для разработчиков

Статический сайт без серверной базы и внешних JS-зависимостей. Для локального запуска с установленным Python: `python -m http.server 8080 --bind 127.0.0.1`, затем http://localhost:8080/. Если порт занят, выберите другой. Обычным игрокам это не требуется.

Для публикации: Settings → Pages → Deploy from a branch → main / (root). Сайт работает по HTTPS.

Графика — упрощённая Canvas-проекция, не полноценная реалистичная 3D-игра. Изображения: см. assets/SOURCES.txt. Права на сторонние изображения принадлежат их владельцам; открытый репозиторий не делает эти изображения свободными для использования.

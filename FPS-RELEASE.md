# FPS release / notes

Новая версия использует единый Canvas raycast FPS для всех смен. Это оригинальная 2.5D-пиксельная игра, не реалистичный 3D-симулятор и не официальная часть Ready or Not.

Что изменено в обучении:
- Первая: поиск теперь требует реального вращения камеры; пары меняются целиком, гарантированно чередуются свой между целями / отсутствует / сбоку.
- Вторая: контроль левой/правой тройки привязан к реальным целям, не любому клику; ошибочный порядок расходует патрон и не наносит урон.
- Третья: реальные точки попаданий определяют кучность; разрешены безопасные разные порядки действий, промах сохраняет прогресс, прямое Q/E. Повторные действия не начисляют серию второй раз.
- Четвёртая: коридор с физическими стенами и дверными проёмами, три сектора, огонь с предупреждением, красная рана, замедление, перемещение при бинте, проверка линий видимости всё время бинта.
- Пятая: достаточно/мало патронов, приблизительная инспекция удержанием R, смена магазина с задержкой и реальная необходимость новой инспекции. Ошибочно начатый сектор можно повторить из паузы, ошибка отмечается.
- Добровольное обучение теперь ждёт действий, не только показывает текст. Оно не записывает результаты и не расходует карьерные дни.

Ограничения: противники стационарны, огонь hitscan с предупреждением (не летящие баллистические снаряды), одна базовая планировка с вариантами укрытий/проходов; это компактный тренажёр, не полноценная кампания. Удовольствие и перенос навыка в другие игры не доказаны автоматикой. Музыка синтезируется локально, проверен ненулевой сигнал; колонки пользователя не проверены.

Регрессионные тесты предыдущих отдельных рендереров остаются в репозитории как legacy. Релиз проверяется tests/fps_*_qa.py плюс сохранение/подписи/таблицы. Проверка таблицы не является прохождением игры. fps_route_qa.py проходит три сектора действиями мыши/клавиатуры без телепортации, но навигационная автоматика читает карту для планирования маршрута.

Профили остаются в lspd-training-v1. Новые результаты получают gameVersion=fps-1 и дополнительные shots/hitCount/misses; прежние записи и подписи не изменяются. Таблицы по-прежнему локальные, не сетевой рейтинг. Старые и новые оценки не следует считать строго сопоставимыми.

Публичный фон вступления заменён оригинальной CSS-композицией. Портрет Альвареса — ранее предоставленное пользователем изображение; права на персонажа принадлежат правообладателям, публичное использование не является обещанием свободной лицензии. Steam screenshot не используется в новом интерфейсе.

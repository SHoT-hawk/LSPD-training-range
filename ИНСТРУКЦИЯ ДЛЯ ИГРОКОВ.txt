Инструкция для игроков

Вариант без GitHub

1. Скачайте архив LSPD-training-range.zip.
2. Нажмите по нему правой кнопкой мыши → Извлечь всё.
3. Откройте распакованную папку.
4. Дважды нажмите «Запустить LSPD.bat».
5. Откроется игра в браузере.
6. Когда закончите играть, закройте чёрное окно запуска.

Нужен Windows и установленный Python 3.11 или новее. Если Python уже не установлен, скачайте его только с https://www.python.org/downloads/windows/ и при установке отметьте «Add python.exe to PATH».

Если Python устанавливать не хочется

Откройте папку игры, щёлкните по адресной строке Проводника, напишите cmd, нажмите Enter и выполните:

python -m http.server 8080

Потом откройте в браузере http://localhost:8080/

Для обычного игрока лучше использовать файл «Запустить LSPD.bat».

Важно

Не открывайте index.html двойным кликом: модули игры и сохранения работают через локальный адрес. Не удаляйте папку assets. Сохранения находятся в браузере конкретного компьютера. Для переноса используйте экспорт профиля.

Если порт 8080 занят: откройте папку игры, щёлкните по адресной строке Проводника, напишите cmd и выполните:

python -m http.server 8081

После этого откройте http://localhost:8081/
